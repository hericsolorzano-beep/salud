# Mi Plan de Salud

Tracker personal para dormir mejor, comer suficiente y volver a entrenar.

Un solo archivo, sin dependencias, funciona sin internet.

## Qué lleva

| Sección | Para qué |
|---|---|
| **Sueño** | Hora de acostarte y levantarte → te dice las horas y si fue suficiente |
| **Proteína** | Botones rápidos por alimento, meta 110 g/día |
| **Entrenamiento** | Un toque por día, 3 veces por semana |
| **Peso** | En ayunas, después del baño |
| **Arriba** | Promedio de 7 días, racha, peso actual y cuánto cambiaste |
| **Abajo** | Historial de 14 días |

## Privacidad

**Tus datos no están en este repositorio.** Se guardan en el
`localStorage` de tu navegador, en tu computadora. El archivo que se publica
está vacío: quien abra el link ve un tracker en blanco y llena sus propios
datos.

El repo es público solo porque GitHub Pages no funciona en repositorios
privados con cuenta gratuita.

## Uso

Ábrelo y llena la fecha, la hora de acostarte y la de levantarte. Le das
**Guardar sueño**. Eso es todo lo necesario cada día.

El botón **Borrar todo** (abajo) reinicia el historial.
